# Swifty Proteins

Visualiseur 3D de protéines pour le projet 42.

## Stack

- **Mobile**: Expo (React Native) + react-three-fiber
- **Backend**: Next.js + tRPC + Prisma + PostgreSQL

## Règle importante

🚨 Tout le code doit **strictement suivre** les exigences du sujet 42.
